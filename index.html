About the project

Anvil lang used to be a compiled C language, Yes I know. Sounds boring right. Well guess what, it was. And it hardly even worked. The origional version was bugged out of its skull with conditionals not working at all and the only way to get output was calling c glibc functions from assembly syscalls. But suffer no longer as a new definition of anvil has emerged from the depths of wsl. And this time, conditionals work, memory safty is a thing and logic is now supported. All of this is thanks to the go programming language. Never did I know there was a language so simple that I could write it without using my brain. But apparently there now is. So this entier version of anvil lang is brought to you by gtref, AI, golang-go and 7 hour nights reading docs. So with all that out of thw way, Please, Enjoy anvil language and hopefully I will see you arround.
